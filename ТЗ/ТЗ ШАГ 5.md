5. API и диск

Справочник: `POST /v2api/{branch}/lead-status/index`.

Тело каталога:

```
{ "page": 0, "pageSize": 500 }
```

**Не копировать пример доки `{"id":1,"page":0}`** — `id` там фильтр одного этапа, на диске останется один статус. Полный каталог = без `id`, page с нуля, pageSize ≤ 500, цикл страниц как в ТЗ-3.
