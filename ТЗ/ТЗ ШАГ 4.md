Метод: `POST /v2api/{branch}/customer-tariff/index?customer_id={id}`  
Тело: `{ "page": N, "pageSize": 500 }` (customer_id допустим и в теле, curl доки: `{"customer_id":1,"page":0}`).

- **`customer_id` обязателен.** В доке endpoint всегда с id. «Страница филиала без customer_id» в доке нет. Текущий `stampLiveTariffsFromBranches` / overlay с `pagedIndex(.../customer-tariff/index, {})` — **запрещён** этим модулем (схема: не выгружать все абонементы глобально).

- Лимит: **общий** 5 rps студии (не щель 200 мс одного файла, не Promise.all в обход лимитера). 429 → backoff. Не красные 5 с шагов 1–5.

5. Предикат «живой» (один на диск, чип, мастер)

Строка живая, если сразу:

1. Есть id строки.
2. Не архив: `dead === true` **или** `Number(removed)===1` / `is_removed===1` — не живая. Дока архива тарифа — `dead`. Студия уже режет `removed`. Читаем оба, что пришло. Нет ни dead ни removed — не считать архивом из воздуха.
3. Срок: `end` (дока) или `e_date` / `eDate` (диск студии) пусто или ≥ сегодня МСК. Как `tariffRowLive`. Просроченный, но не архивный в Alfa — **не** «С». Это дыра старого текста ТЗ-4, здесь закрыта.
4. Пустой tariff_id (подпись «абонемент») живую строку не гасит — как сейчас tariffRowLive.

Иначе не живая. Архивные/мёртвые строки этого id в том же прогоне убрать/погасить.

live_tariff="1" только если после слияния по запрошенным филиалам есть хотя бы одна **живая** строка; иначе "0". Не оставлять старую "1" при нуле живых, если поле чистое.

Не писать вторую функцию живости. Расширить `tariffRowLive` чтением `dead`, не копировать формулу в модуль 7.
