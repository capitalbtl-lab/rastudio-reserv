2. Форма штампа на диске

Рядом с досье, не второй мозг роли. Один словарь на customerId:

- fields: имена из таблицы, которые грязные
- at: ISO (на поле или на запись; снятие по полю)
- source: site | olga | queue
- ackedAt на поле — когда сняли

Нет поля в словаре = чистое. История 1–5 словарь не читает (их код не трогаем). Читатели: хелпер для ТЗ-3…5 и очередь, если уже пишет эти extras.

Один носитель: модуль вроде crm-field-dirty.ts + запись в существующий sync JSON по customerId (рядом со штампами А, не вторая карта людей). Не раздувать dossiers.json второй картой ID. Если extras — одна строка JSON, не status2.

Экраны в ТЗ-1 бейдж не обязаны.

5. Когда снимать (ack = тот же метод, что менял поле)

Только успешный ответ очереди **по этому полю**:

- Роль / архив строки / филиалы / этап человека: `POST /v2api/{branch}/customer/update?id={id}`. Этап — скаляр `lead_status_id`. Не `lead-status/update`.
- Абонемент: create/update/delete `customer-tariff` (в доке `customer_id` обязателен на URL). Не pay.

Пустой ответ / HTTP 429 / сеть — dirty жив. Дока: лимит **не более 5 запросов в секунду на любые методы, включая авторизацию**; 429 → backoff. Счётчик skip inbound не путать с ack.

Не снимать по таймауту. Не снимать, потому что пришла ночь 1–5. Inbound 6–8 не вызывает clearDirty.
