# Канон шага 5 — метод остатка (редакция 45)

Шаг 5 кассу и журнал не качает. Считает остаток с диска и сверяет с `Customer.balance`.

## Формула (вместо старой «товар не в остатке»)

```
остаток = приходы
        + корректировки (как есть: плюс прибавляет, минус вычитает)
        + возвраты (в Alfa сумма плюсом, с остатка вычитается)
        − списания проведённых занятий
        − продажа товара
```

Совпало, если `|остаток − шапка| ≤ 1 ₽`.

Шапка — только живой `balance` после А шага 4 (`payFill.full === true`). `complete[]` кассы шаг 5 не читает.

## Слагаемые

| Строка карточки | Откуда | Знак |
| --- | --- | --- |
| Платежи | pay/index тип 1, диск шага 4 и живой при «Перепроверить» | плюс |
| Списания занятий | календарь шага 2, `lessonId`, **status = 3**, `amount` | минус |
| Корректировки | тип 6 | как в строке |
| Товар | тип 9 (старый 2) | минус, продажа вычитает из остатка |
| Клиенты / формула | расчёт выше | итог |
| Шапка / итог | `customer/index` → `balance` | как отдала Alfa |

План, отмена, не проведённые в списания не входят. Пропуск — только если урок всё равно status 3 и с суммой.

Списания в колонке Alfa — то же число и сумма с календаря, который шаг 2 забрал из Alfa. Отдельного pay/index по списаниям нет.

## Что снято

- Товар «в ленте есть, в остаток нет» — не закон. В сверке взаиморасчётов продажа товара — расход, шапка его уже вычла.
- Формула = только платежи − списания без товара — не закон.
- Подставлять шапку из `extras.balance` — не закон.

## Карточка

Порядок строк: платежи → списания занятий → корректировки → товары → Клиенты / формула → шапка.

В «Клиенты / формула» колонка Alfa: приходы − списания ± корректировки − товар = итог.
