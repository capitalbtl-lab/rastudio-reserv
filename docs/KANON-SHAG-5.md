# Канон шага 5 — метод остатка (редакция 50)

Шаг 5 кассу и журнал не качает.

## Формула

остаток = приходы + корректировки (±) + возвраты (вычитаются) − списания status=3

Товар в ленте pay есть. Дока ТМЦ: «Продажа товара не влияет на остаток клиента».
В формулу товар берём только если живая шапка `Customer.balance` без него не сходится
(часть старых наборов/поездок шапка уже держит). Иначе не минусуем — иначе «касса меньше шапки» на сумму набора.

Совпало: |остаток − Customer.balance| ≤ 1 ₽ после живой шапки.

## Пустая лента

Нет платежей → 0 и 0 ₽.
Нет занятий → 0 и списания 0 ₽.
Нет корректировок → 0 и 0 ₽.
Нет товара → 0 и 0 ₽.

Считаем формулу и шапку как обычно. 0 = 0 = 0 — Совпало, вправо.
«Кассы нет — не сверяем» снято. А шага 4 для пустой ленты не требуется.
