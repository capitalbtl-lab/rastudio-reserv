## Ошибки в коде

1. **Потолок 12×100.** `censusCustomerLessonIds` при полной 12-й странице ставит `ok: true`. Prune по обрезанной переписи сотрёт хвост. Пока последняя страница length=100 — `ok: false`, prune нельзя.

2. **3a и `applyCustomerLessonCensus`.** Проба / «Добрать» / сорванная перепись = keep (3a). Закрытая полная перепись синей = живое число (3b), **кроме** cid с `journalHoleApprovedAt`: живую цифру можно обновить, `lessonsFull` нельзя, missing нельзя.

3. **Fan-out vs `customer_id`.** Журнал группы сажает id, которого индекс ученика не знает. Prune по переписи снимет чужую качку. Id с `loadGroupCard` её групп не снимать.

4. **Замок не общий.** Качка ученика — `waitLockStudentAlfa`. Журнал группы / fan-out — нет.

5. **Синяя качает с 2015** (`inboundCustomerLessons` full × 6), потом census, потом prune. Для extra тела не нужны. Для одобренной дырки качка тел **запрещена**.

6. **Ядро очереди не знает галку.** `peopleJobFinished` / `shouldRetryShortPeople` смотрят `short`, не `holeApproved`. Красный job и ретрай снова «Добрать» одобренного, если cid попал в `items`. Фон пакет `lessons` обходит досье без штампа дырки — качнет 2124 даже с галкой.

7. **Синяя очередь экрана** кладёт `short && holeApproved` в «Перепроверить по одному». Ядро не должно по этому cid делать missing/полный inbound/закрытие.

## Закон

### 0. Одобренная дырка

Есть `journalHoleApprovedAt` и `short`:

| Кто | Делает |
|---|---|
| Галка / `holeApprove` | только штамп |
| Красная «Загрузить по одному», `people` job, `shouldRetryShortPeople` | **пропуск cid** |
| Фон пакет `lessons` | **пропуск cid** |
| Фон `journal` / fan-out / карточка урока | писать урок можно, штамп дырки не трогать, `lessonsFull` не ставить |
| «Добрать» на карточке | как сейчас, человек явно; штамп дырки не снимать |
| Синяя | шаг A (перепись) можно; missing и полный inbound **нет**; prune extra по шагу C можно; `lessonsFull` / снятие галки **нет** |
| Снять галку | только `holeApproveClear` |

Пропуск ≠ закрытие. `lessonsFull` не писать, пока диск < Alfa.

`PeopleJobRow` / `peopleJobFinished` / `peopleJobQueue` / `shouldRetryShortPeople` / `inboundCustomerLessonsChunk`: если `customerSyncOf(cid).journalHoleApprovedAt` и short — не качать. Это ядро, не экран.

### 1. Синяя, extra (диск > Alfa), галки нет

A. Перепись за всю жизнь. Последняя страница 100 или 429 → не закрыта, keep, prune нет.  
B. Равенство → `lessonsRecheckAt`, тел нет.  
C. Prune id, которого нет в переписи **и** нет в hold / local / календаре группы ученика.  
D. Дырка (диск < Alfa) **без** галки → `inboundMissing` по id, не take:8 с 2015.  
E. Дырка **с** галкой → D запрещён.

### 2. Чужие загрузчики vs prune

| Кто | Календарь cid | Синяя / prune |
|---|---|---|
| Фон `lessons` | inbound cid + штамп счёта | замок; **skip если галка** |
| Фон `journal` | fan-out, штампа счёта нет | id на группе не prune |
| Кнопка группы / ДЗ / урок | fan-out | то же |
| Пробный | часто id < 0 | hold |
| Ночь групп | состав | журнал не трогает |

Не второй файл, не вторая очередь.
