## Закон этой правки

### 1. Окно — только перепись и prune keepBefore

Уже есть: `censusFrom = windowFrom || from`, `apply(..., windowFrom)` → `keepBefore` не снимает строки старше окна, `lessonsAlfa` из apply при окне не пишет.

Не менять.

### 2. Extra в окне — не качать

Ветка `else if (windowFrom && !holeApproved) { extraIds = have \ census; inboundMissing }` — **убрать**.

Старые id не в месячной переписи — это норма, не extra месяца. Они уже на диске. Повторный fetch запрещён.

Не делать «extra только с датой ≥ windowFrom, потом inboundMissing»: тело уже лежит, вызов Alfa бессмысленный и снова раздувает строки (`countAlfaLessonRows` считает дубли).

Fan-out за месяц, которого нет в `lesson/index` ученика, **остаётся на диске**. Prune с `keepBefore` + `lessonIdsOnStudentGroups` его не снимает. Так в 3b. Не качать.

### 3. Missing в окне — можно, только id из этого census

`short && !holeApproved` → `inboundMissing(census.ids \ have)`. Census уже с `dateFrom` окна. Это новые за месяц, которых нет на диске. `take: 50`, `force: true` как сейчас (синяя — явный жест; галки нет).

Не вызывать `inboundCustomerLessons` full / 2015 в синей. Тест 3b `doesNotMatch inboundCustomerLessons` в recheck-срезе — не ломать.

### 4. mark после окна без bump

После missing (или без него):

```
mark(disk, alfaN, census.ok)
```

Не `Math.max(alfaN, alfaN + bump)`.  
`alfaN` из apply при окне = keep (живой счёт). bump не аргумент.

`census.ok === false` уже идёт в `mark(disk, 0, false)` — keep 3a, prune нет. Не трогать.

Полная синяя (не green, без окна): `mark(disk, alfaN, true)` при `census.ok`, без bump. `alfaN` = `keepAlfaProbe(keep, uniq.length, true).alfa`. Слабее keep не писать (уже в apply).

### 5. Что синяя на зелёном делает после правки

1. Перепись филиалы 1–4, status 3/1/2, `dateFrom` ≈ −32 дня, потолок 12×100. Страница 100 → `ok: false`, apply нет.  
2. Apply с `keepBefore` = окно. История старше окна на месте. `lessonsAlfa` не из uniq.length.  
3. Если диск < keep и нет галки — добрать missing **этого** census, не больше 50 за шаг.  
4. Если диск ≥ keep — тел нет.  
5. `lessonsRecheckAt` только из `mark` при `closed` (проба живая, не short, не extra, нет галки). Extra на группах может оставить `dups` — карточка справа, `lessonsFull` нет. Так задумано 3b.

«Всю Alfa не качает» = нет `inboundCustomerLessons`, нет `inboundMissing` по id старше окна, нет bump счёта.

Перепись за месяц — это **номера**, не журнал. Так и должно: несколько страниц `lesson/index`, не тела уроков.

### 6. Не green (ещё ни разу не сошёлся, но уже справа)

Кто это: пустой журнал 0=0 (alfa=0 → `wasLessonGreen` false) или редкий край. Окна нет, `from` с экрана (годы / 2015). Extra-ветки нет. Missing если short. Полный prune без keepBefore — 3b, не этот ТЗ.

Слева short синяя не берёт (`peopleJobQueue`). Седышев 495<541 на этом ТЗ **не** объект. Его путь — красная / галка / отдельный счёт uniq. Не подменять.
