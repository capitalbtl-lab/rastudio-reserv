## Шаг 1. Синяя (`balance && recheck`)

Сначала **тот же** блок окна, что шаг 2 синяя:

1. `recheckCensusWindow(sync, recheckDays)` → `date_from = сегодня−N`, `date_to = сегодня+N`. N = 32 | 92 | 182. Не 2015. Не полный fill.
2. Перепись id в окне. Обрыв страницы → не prune, не `lessonsRecheckAt`.
3. `keepAlfaProbe` / `windowAlfaKeep`. Слабая проба не занижает.
4. Prune только id **в окне** с датой. `lessonId` 0 и − не резать. Свои и очередь — держать. Групповые — protect.
5. Missing новых в окне, `take` 50, тела `{ id, status: 1|2|3 }` по филиалам. Нет даты — dropped, не 2015.
6. Готово журнала: hole=0 и extra=0 по id, `diskRows === diskUniq`. Не checksum. Не `disk === alfa` без набора.
7. Галка: missing не трогает, журнал не закрывает.

Потом касса **как сейчас**: `inboundCustomerPays`, курсор, страницы. Не фильтровать `pay/index` окном ±N.

`paysRecheckAt` — только после `scanDone` кассы. Не из `mark()` календаря.
`lessonsRecheckAt` — только если журнал окна закрыт по id (п. 6).
