## 1. Аккордеон

`toggleOpen(id)`: повтор по той же — закрыть, другая — открыть одну.

- Клик **по названию** = клик по «+».
- Открыли Б — А закрылась. Не две простыни.
- «+» на **заголовке колонки** «Загрузка завершена» / «Требуют загрузки»: сворачивает **список колонки**, не карточку. «−» когда колонка открыта. Состояние `needOpen` / `doneOpen` в `sessionStorage` ключ `ra-hist-col-{tab}-{side}`. Завод: обе открыты. Не путать с `open` карточки.
- Раскрытие карточки **не** `scrollIntoView` к верху страницы.
- Высота свёрнутой карточки **фиксированная** (шапка + FillBar + 2 строки).

Не `max-h` + внутренний скролл списка групп. Страница сайта скроллится целиком.

## 2. «Готово» только в конце зерна

Сейчас у квартала статус сверху (`h-4` «готово» / «отмечено») **и** кнопка деталей «готово». Путаница.

Правило:

- Кнопки: «Загрузить явки · III кв.» / «Перепроверить» / «Загрузить детали · N». **Не** подпись «готово» на кнопке. Выкл детали: серая «детали на месте» или скрыть (`disabled` + muted).
- Убрать фразу **«грузить нечего»** (`noHw ? "грузить нечего"`). Замена: «проведённых нет, детали не нужны».
- Процесс в шапке не прыгает. Строка `загрузка · III кв. 2026` — `h-5 truncate`, оставить.
- В **конце** блока квартала (под датой сверки, одно место, class `data-fill-end`):  
  `Проставлено` (есть pulled) → `Отмечено` (done, не weak) → `Готово` (явки + не weak; детали отдельно ☑).  
  Бейдж шапки карточки «загрузка завершена» — про **всю** группу, оставить.
- Кнопка-действие «Готово» шага 3 **не** в карточке квартала.

`windowAt` (этап 4): серая строка «окно 14 дн. · 11.09 16:40», **не** `bg-emerald`, **не** перенос вправо.
