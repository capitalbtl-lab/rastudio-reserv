## 1. Расширить тип, ядро без fs

`agent-client-desk-core.ts` или `crm-desk-digest-core.ts`:

```ts
type DeskPastLesson = {
  date: string;              // ДД.ММ
  groupName: string;
  attend: boolean | null;    // null = не отмечен
  topic?: string;
  homework?: string;
  note?: string;
  grade?: string;            // только этого customerId
  homeworkGrade?: string;
  skip?: boolean;
};

type DeskFuture = {
  date: string;
  time: string;
  kind: string;              // group | trial | makeup | individual | …
  groupName?: string;
  teacher?: string;
  room?: string;
  makeupSpare?: number;      // только group-слот, этап 6

type DeskPay = { date: string; sum: number; kind: string };

type ClientDigest = {
  /* старые поля + */
  past: DeskPastLesson[];
  future: DeskFuture[];
  pays: DeskPay[];

  lessonsLeft: number | null;
  skipNote?: string;
  commsHint?: string;
  holes: { journal?: boolean; money?: boolean; details?: boolean };
};
```

## 2. Что класть с диска

**past** — `loadCustomerCalendar` + строка группы только **этого** id в `pupils`. Проведённые, новые сверху, взять N. Тема/ДЗ/примечание с урока. Оценка — `pupils` где `customerId` совпал. Нет `detailsAt` и пусто тема — `holes.details`, в промпт «темы нет в карточке, не выдумывать курс».

**future** — слоты его `groupLinks` на горизонт + его запланированные trial/makeup/indiv + ключи occupancy коллег на **его** teacher/время. Не весь филиал. Кэмп в future: `canOfferSummer`.

**pays** — 3–5 последних `paysOf` этого id, не poll 3 дня как «вся правда».  
**money** — `displayedBalance` / снимок карточки, не `paid_till`.  
**lessonsLeft** — остаток занятий абонемента, не рубли.

**skip / pause** — как сейчас.  
**comms** — не тексты переписки в промпт. Пометка «лента comms есть / пусто». Не выдумывать «вы вчера писали».

Чужой состав группы именами не включать. Только имя ребёнка карточки.

## 3. Промпт дайджеста

`digestPrompt(d, policy)` дополнить блоками. Кухню Alfa не писать **в им-слой**. Для админ-стойки `deskDigestPrompt`: без gid вслух, с «себе: id».

Обязательные строки себе:

- прошедшие N: дата, группа, явка, тема, ДЗ, его оценки, примечание — или «поля нет»;
- будущие горизонта: слот, spare отработки если group;
- «нет строки журнала — не рассказывать программу»;
- «чужие оценки запрещены»;
- деньги и занятия раздельно;
- «не обещать вся история сверена»;
- «не отработка сверх spare»;
- подтянуть ≠ сохранить; регулярку не двигать.

Им-слой в `deskAdminPrompt` — **не переписывать** полотно. `DESK_REV` bump. Добавить абзац «УЧЁБА С ДИСКА» (~15 строк) после действующего клиента: зачитать ДЗ/тему если в карточке; иначе «секунду» + один id **если** `pull.adminVoice`; консультанту сайта при выкл — телефон / «уточню у администратора».

`FACTORY_GUIDES` / `SCHEDULE_NEVER` — **дополнить 4–6 пунктами**, не удалять старые:

- не обещать «вся история сверена» по короткому окну / дайджесту 21 дня;
- не оценка соседа;
- не ДЗ, если нет строки и детали не смотрели;
- не путать Фон и Историю вслух;
- не отработка сверх запаса;
- лето без сезона и галочки.

`IDS_FOR_AGENT` — не трогать.
