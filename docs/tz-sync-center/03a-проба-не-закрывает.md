## 1. Один закон штампа

Файл: `keepAlfaProbe` в `src/data/crm-inbound-core.ts`. Читают: `pullOneStudent` → `mark()`, ветка `opts.probe`, `applyCustomerLessonCensus`.

```
keep = Number(lessonsAlfa) на диске
write только если probedOk и не (keep > 0 и alfa < keep)
иначе lessonsAlfa / lessonsAlfaAt не трогать
lessonsDisk можно обновить с календаря
closed = probedOk && write && !short && !extra
lessonsFull / lessonsAttend / lessonsRecheckAt — только из closed
```

`lessonsCountShort` / `lessonsCountExtra` / `lessonsJournalReady` **не расширять**.

Skip inbound (красная «по одному», не синяя):

```
first.ok && !weak && disk >= max(alfa0, keep) && !extra
weak = first.ok && keep > 0 && alfa0 < keep
```

Не: `disk >= alfa0` без keep.

Census синей: **не** `lessonsAlfa: uniq.length` в обход. Тот же `keepAlfaProbe`. Иначе 286 снова станет 254.

## 2. Что это значит для центра

| Поток | Пишет Alfa-число | Закрывает cid |
|---|---|---|
| Проба молчит / 429 / catch | ничего | нет |
| Проба < keep | ничего | нет, качать дальше |
| Проба ≥ keep, диск < Alfa | Alfa если больше keep | нет, жёлтый short |
| Проба живая, диск = Alfa, нет extra | Alfa | да, full |
| Диск > Alfa | Alfa не занижать | нет, extra / дубли — закон синей |

Правый столбец «загрузка завершена» **не** ставит проба. Short живёт, пока `lessonsDisk < lessonsAlfa` при живом `lessonsAlfaAt`.

Воркер `rastudio-history` читает `src/`. После правки штампа — `pm2 restart rastudio-history`, не только сайт. Иначе старый процесс пишет во время сборки.

## 4. Приёмка на диске

После шага по cid:

- `lessonsAlfa` не меньше уже известного, если проба молчала или вернула меньше
- `lessonsAlfaAt` не пустеет, если уже был
- `lessonsFull` не true, пока диск < Alfa
- соседний cid не в `items` — не меняется

Простыми словами: проба не может сказать «готово», если Alfa молчала или насчитала меньше, чем уже лежит на диске. Дырка остаётся дыркой, пока занятия не докачали.
