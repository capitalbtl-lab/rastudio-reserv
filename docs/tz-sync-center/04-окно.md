## 2. Окно дат (ядро, МСК)

`windowRange(now, policy) → { from, to, days, label }`

- `to` = сегодня МСК 23:59 (`Europe/Moscow`, не Chicago сервера).
- `from` = to − `history.days` + 1 календарный день (14 дней = сегодня и 13 назад).
- пресет `quarter` = текущий квартал МСК с 1-го числа.
- `days` clamp 1–90, как `policyOf`.
- Строки в Alfa: `YYYY-MM-DD` через `toAlfaLessonDate` / `ymd`.

Тест: `2026-09-11 02:00+03` + 14 дней → from `2026-08-29`. Не UTC-вчера.

Архив: `history.archiveStudents` / `archiveGroups` завод false → в выборке только живые (`is_study=1`, группы не status 3, не кэмп). Вкл — отдельный прогон, не смешивать в одном курсоре. Завод — один курсор live.

## 3. Курсор на диске

`storage/crm-history-window.json` (не policy, не packet-queue):

```ts
{
  status: "off" | "running" | "paused" | "done",
  enabledAt: iso,
  from: "2026-08-29",
  to: "2026-09-11",
  days: 14,
  step: "calendar" | "groups" | "money",
  i: 0,
  total: 0,
  who: { kind, id, name },
  ok: 0,
  fail: 0,
  note: "",
  stopAfterPacket: false,
  nextNotBefore?: iso,
  updatedAt: iso
}
```

Рестарт node: `running` продолжает, лок пуст — conductor снова берёт window.  
`off` — курсор можно не тереть. Старт переписывает from/to с политики **на момент Старта** (сменили 14→7 посредине — текущий прогон доезжает старое окно; следующий Старт уже 7).

Стоп: `stopAfterPacket: true`, после текущего inbound `status: paused`. Не убивать HTTP посередине.

## 4. Один пакет окна

Порядок, если шаг в политике вкл (`history.steps`):

1. **calendar** — ученики выборки по одному `customer_id`.  
   `inboundCustomerLessons(..., { force: true, dateFrom: from })`.  
   **не** ставить `lessonsFull`. Штамп: `windowAt` / `windowDays` на customer-sync.  
   **не** `rechecked`, **не** `alfa` probe.

2. **groups** — живые группы по одной, зерно = всё окно дат, не квартал жизни.  
   `inboundJournalGroup(bid, gid, { lite: true, deep: false, dateFrom, dateTo, force })`.  
   merge union, только строки окна.  
   штамп карточки: `journalFill.windowAt`, `windowFrom`, `windowTo`.  
   **запрещено** `pulled[q]=`, `done[]+=`, `rechecked[q]=`.  
   weak не ставить на квартал из-за короткого окна.

3. **money** — по одному ученику `pay/index` (+ tariff за те же даты при необходимости).  
   штамп `paysWindowAt`, **не** `paysRechecked` «вся касса».  
   не глобальный `slice(-40000)` (этап 5). Не вызывать полную выгрузку филиала.

`history.windowPullsDetails === false`: **не** enrich / не `deep: true` / не lesson get по 16. Тема/ДЗ не качать.

Пауза между пакетами: `history.pauseSec` (15), не путать с ручной 5 с.  
Правило: `nextNotBefore = now + pauseSec`; conductor skip window пока рано.

Пакетов за тик: 1.  
Ошибки одной группы: `fail++`, note с id, **идти дальше**.
