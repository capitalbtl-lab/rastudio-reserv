## 1. Что меняем, что нет

**Меняем**

- единый лок «кто в Alfa»
- `idleAlfaTick` = **один** слот дирижёра, без `kickBackground()` пачкой
- интервал тика из `policy.tickSec` (завод 20)
- пауза 429 из `policy.pause429Sec` (завод 60) вместо 2 с
- капельница journal/lessons **только если** `dripQuarters === true` (завод **false** → ночной журнал **молчит**)
- `journalPull` берёт лок `manual`, фон ждёт

**Не меняем**

- кнопки и вёрстка Истории
- смысл `journalPull` (force, зерна, склейка)
- `pickTeacherIds` нет, inspect слота
- галочки `saveAlfaLink` не вызывают `enqueueJournalOverlay(true)`
- take у `tickCrmQueue` с тика = **1**
- процессы `night-groups` и `pay-poll` **не убивать**
- `nightHour` **не читать** (каталог 04:00 как был)

## 3. Лок

Файлы: `src/data/crm-alfa-lock-core.ts` (без fs) + `src/data/crm-alfa-lock.ts`.

```ts
type AlfaLockHolder =
  | "export"
  | "payPoll"    // этап 5 cron, в 2 не вызывать
  | "colleague"  // этап 5
  | "delta"
  | "window"     // этап 4
  | "drip"       // journal | lessons | overlay пакета фона
  | "night"
  | "manual";    // journalPull / «по одному» / «Загрузить 10»
```

API: `tryLock(holder)` → `{ ok, holder, since }`; `unlock(holder)` только свой; `lockSnapshot()`; `isHeld()`; `holderRank(h)`.

Память процесса (`globalThis`), не JSON. Рестарт node = лок пуст.

**Вытеснение**

| Кто пришёл | Кто держит | Что |
|---|---|---|
| night | drip / delta | night **ждёт конец текущего пакета**, новые drip не стартуют (`__raNightGroups` как сейчас) |
| manual | drip / delta / export lean | manual **после текущего пакета**; новые idle-слоты skip. Export **не** рвать на середине `pay.create` |
| export (не lean) | drip | export после текущего drip, на следующем тике **раньше** drip |
| drip | export | drip skip, тик отдаёт export |
| кто угодно | тот же holder | reentrant нельзя: второй `tryLock` false |

Таймаут лока: holder жив **> 3 мин** — снять, `lastNote` «лок снят по времени». Это **не** таймаут HTTP `journalPull` (25 с у «Догрузить текущих»). Не путать.

## 4. Дирижёр

Вынести выбор из `idleAlfaTick` + `kickBackground` в `src/data/crm-alfa-conductor.ts`.

`conductorStep()`:

1. Если `!alfaLinkedNow()` → стоп (очередь экспорта копится как сейчас).
2. Если лок занят → стоп.
3. Если `__raNightGroups` / holder night → стоп inbound.
4. Если флаг «ручная История идёт» (`waitManual`) → стоп inbound.
5. Если `Date.now() < backoffUntil` (429) → стоп.
6. Иначе **ровно одно** по §2 (пустые слоты skip):
   - исходящая очередь не пуста → `tickExportQueue(1)` // не 3
   - иначе дельта клиентов, если канал customers и due по `minutes`
   - иначе дельта лидов, если канал leads и due
   - иначе пакет `pickNextPacket`, `tickCrmQueue(1)`: journal/lessons в очередь ставить только если `dripQuarters`; overlay/cgi как сейчас по TTL канала clients
   - иначе `tickExportQueue(1, { lean: true })`

`kickBackground()` удалить как веер или оставить пустой обёрткой. Сейчас её зовут `idleAlfaTick` и `ensureAndTick` — оба перевести на `conductorStep()`.

`ensureAndTick({ force })` («Обновить» / вход):

- **не** класть сразу overlay+journal+lessons тремя enqueue;
- force → один `enqueueCrmOverlay(true)`; journal/lessons **только** если `dripQuarters`;
- затем `conductorStep()`, не `tickCrmQueue` + `kickBackground` пачкой.

Галочка pull «Журнал» выкл → drip не ставится, даже если `dripQuarters` (канал главнее).  
`dripQuarters` выкл, канал вкл → **ручной** `journalPull` жив (`force`), фон не капает.

Это главное видимое изменение этапа 2: после выкладки ночной журнал **перестаёт** сам идти, шаги 1–3 руками работают.

## 6. Ручная История и лок

В `journalPull()` (сервер, `crm-journal-pull.ts`):

- вход: `tryLock("manual")`. Занято night → `{ ok:false, error:"ночь каталога, повторите через минуту" }` без Alfa. Занято export середины pay → подождать **до 5 с** или сразу таймаут **25 с** как у «Догрузить текущих», не висеть минуту.
- `finally`: `unlock("manual")`.
- Пока manual: `conductorStep` inbound return.

Кнопки UI не менять. Busy на карточке как сейчас.

«По одному» / «Загрузить 10» / квартал группы — все заходят в `journalPull` → один лок на **HTTP-запрос**. Закрыли ноут — лок не должен жить.

## 10. Тесты

Ядро без Alfa, без `group-cards.json`:

1. `pickConductorSlot`: export не пуст → export; иначе delta due → delta; иначе journal в очереди и drip вкл → drip; drip выкл → journal **не** выбирается, берётся overlay или lean export.
2. Слоты payPoll / colleague / window в этапе 2 = skip.
3. `dripQuarters false` + канал lessons → `enqueueJournalOverlay` не добавляет packet.
4. `tryLock("drip")` затем `tryLock("manual")` → manual не вышибает drip насильно, флаг `waitManual`; после unlock drip следующий tryLock manual ok.
5. Двойной `tryLock("drip")` → второй false.
6. Unlock чужого holder — no-op.
7. `pause429Sec`: 10 → 30; `tickSec`: 5 → 10.
8. Регрессия `pickNextPacket`: group раньше journal.
9. Регрессия: `saveAlfaLink` / смена галочки **не** содержит `enqueueJournalOverlay(true)`.
10. `kickBackground` не вызывает три inbound параллельно (либо функции нет, либо `conductorStep` один kind).
11. Ночь: `__raNightGroups` → conductor skip night.

Существующие `crm-packet-queue-core.test.ts`, `crm-alfa-link-core.test.ts`, `crm-night-groups.test.ts` — зелёные. Не гонять live `lesson/index`.
