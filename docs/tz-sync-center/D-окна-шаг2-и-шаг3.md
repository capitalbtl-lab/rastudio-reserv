## Зачем

Человек видит шаг 2: красная рамка + годы, синяя рамка + «месяц / три / шесть».
Шаг 3: две кнопки подряд и «Квартал» посередине, синего окна нет.
Ядро шага 3 синяя уже ходит **±32/92/182**. Экран шлёт `grain`, `recheckDays` не передаёт — на сервере всегда 32. Человек не выбирает, не видит ±.

Нужно: **одна картинка** на шаге 2 и шаге 3. В обоих шагах синяя рамка — **± месяц / ± три / ± шесть**.

## Закон

Правда на диске. Alfa — очередь ядра. Ключи: `branchId`, `groupId`, `customerId`, `lessonId`. Не имя.
Окно синей — не порция красной. Не подменять `grain` на `recheckDays` и наоборот.
Красная шага 2 читает годы (`2015` / 7 / 3 / 1). Красная шага 3 читает `grain` (квартал / полугодие / год).
Синяя обоих шагов читает только `recheckDays`: `32 | 92 | 182`.
Ядро: `clampRecheckDays`, `recheckCensusWindow` — `date_from = сегодня−N`, `date_to = сегодня+N`. Не «месяц назад».
Второй селектор синей не плодить. Второй `BtnCluster` не писать с нуля — он уже есть.

## Что передать в ядро

Уже есть поле `recheckDays` у `startHistJob` / `runJournal` / job.

```
recheckGroupsOne:
  startHistJob({
    jobMode: "groups-recheck",
    grain: journalGrain,          // очередь «кого», не окно дат
    school, recheck: true, archived,
    recheckDays: groupsRecheckDays,
  })
```

Синяя на карточке группы (`Перепроверить` у порции, когда `loaded`): тоже `recheckDays: groupsRecheckDays`.
Красная «Загрузить явки · квартал» — **без** `recheckDays`, как сейчас `dateFrom/dateTo` порции.

Шаг 2 уже шлёт `peopleRecheckDays` — не ломать.

Ядро само ставит ±N. Экран даты в запросе не считает.

## Критерий готово

1. Шаг 2 и шаг 3: красная кнопка в красной рамке со **своим** списком; синяя — в синей со списком **± месяц / ± три / ± шесть**.
2. На шаге 3 в синей рамке список виден без прокрутки ряда (как на скрине шага 2).
3. Смена ± три на шаге 3 → `groups-recheck` уходит с `recheckDays: 92`. Сеть/лог job. Не 32 по умолчанию.
4. Смена «Полугодие» на шаге 3 → красная по-прежнему режет порцию полугодием. Синяя это игнорирует.
5. `i` синей рамки на обоих шагах говорит «в обе стороны от сегодня», не «месяц назад».
6. Ядро не диффается.

Простыми словами: шаг 3 должен выглядеть как шаг 2 — красное с порцией, синее с ± месяцем. Синяя на обоих шагах смотрит месяц вперёд и назад, не только прошлое.
