## Id и строки — не одно «готово»

## API (официальный v2api, не выдумывать)

`POST /v2api/{branchId}/lesson/index`  
Тело: `group_id`, `status` 1\|2\|3, `date_from`, `date_to` (**YYYY-MM-DD**), `page`, `pageSize`.  
Без `customer_id`. Без `?id=` в URL. Без `lesson_id`.  
Без `status` Alfa отдаёт только 3 — цикл 1/2/3 обязателен.  
Урок живёт в филиале из URL. Фильтры — И.  
Схлопывание: `id:{lessonId}`, не `id\|date\|from`. Один урок — один ключ.  
Страницы status: `received += items.length`; конец, если `total > 0 ? received >= total : items.length < pageSize`. Не «8 страниц и готово». `pageSize` 100 (до 500 по доке).

## Что сравниваем

В текущем окне (квартал красной **или** дни синей):

* **census** — уникальные `lessonId` из ответа **после** фильтра «этот `group_id`» (все status, страницы дочитаны). Чужой `group_ids` в census не класть.
* **have** — уникальные `lessonId` на group-card в этом окне (`date` урока).
* **hole** — в census, нет в have.
* **gone** — в have, нет в census (не hold очереди, не `lessonId < 0`).

Пустой census при **дочитанных** страницах и живом ответе — валидный ноль: gone = have окна.  
`lessonsSetGap` шага 2 при пустом seen extra не считает (чтобы не тереть диск ученика). **Не менять** эту функцию. Gone на группе при пустом census считать явно.

## Готово окна

```
страницы 1, 2 и 3 дочитаны
и hole пустой
и (синяя: gone пустой после prune; красная: gone можно оставить)
```

Не готово: обрыв, `got < total` у любого status, сеть, `hitCap`. Тогда не prune, weak, не «сошлась».

Красная: hole пустой + страницы дочитаны → порция done. Extra (gone) не мешает красной. Снимет синяя окна.

Синяя: hole и gone пустые после посадки и prune.

## Синяя

1. Тот же `lesson/index` **окна дней**, status 1/2/3.
2. Upsert новые на group-card.
3. Перепись полная → снять с group-card только gone **этого окна**. Вне окна не трогать. Hold / локальные id не трогать.
4. Не early return `samePrint` + union: иначе ушедшие останутся.
5. `fanOutLessonWriteoffs` только новые, что сели на группу. Не весь журнал группы.
6. На ученике: `noteAlfaLessonsLanded(cid, disk, newIds)` **как есть**. Диск и `lessonsSeenIds` += эти id. **Не** `lessonsAlfa += n группы`. **Не** keep+N от длины порции. **Не** `lessonsFull`. **Не** `lessonsRecheckAt`.
7. Ушедшие с **личного** календаря не снимать. Это синяя шага 2, когда id уже нет на group-card.
