## Шаг 5. Подсказки

`HINT.recheckWindow` — «в обе стороны», не «только шаг 2».

`HINT.recheckOneMoney`:

> Синяя очередь справа на шаге 4. Окно — список в этой же синей рамке (± месяц / ± три / ± шесть), не годы из красной. Сначала сверка журнала по номерам уроков в окне. Потом касса — все страницы, не окно дат. Вправо, когда страницы кассы дочитаны, даже если уроки не сошлись (дырка — шаг 2). Сумма с шапкой — шаг 5. Пауза 5 с. Стоп после текущего. В Alfa не пишет.

`HINT.loadOneMoney` — убрать «вправо по ±1 ₽»:

> Красная очередь слева, по одному, пауза 5 с. Касса на диск. Вправо, когда страницы дочитаны или касса уже была. Сумма с шапкой — шаг 5. Если журнала нет — одна пачка уроков по годам из этой же красной рамки, не «Добрать до конца». Платежи годы не режут. Синяя рамка не читается. В Alfa оплаты не создаёт.

`HINT.yearsMoney`: только красные шага 4 и «Загрузить кассу». Свой список, не шаг 2. Режет календарь, если его ещё нет. Платежи нет.

`HINT.loadPay`: «окне лет» оставить для красной карточки. Не обещать полное закрытие журнала.

`HINT.recheckPay`: окно синей рамки для журнала; касса — все страницы.

`HINT.tabMoney`: красная — годы, синяя — ±. Не «справа те же годы» на обе.
