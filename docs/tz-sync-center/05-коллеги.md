## 2. Касса: хвост по ученику (Д5)

Ядро `crm-pay-core.ts` (тесты без диска):

- `capPaysByCustomer(items, perCap)`: для каждого `customerId` оставить не больше **4000** своих строк (новые id/даты с конца). Чужие id не выкидывать ради общего лимита.
- `perCap = 4000` зафиксировать в тесте.
- Глобального `store.items.slice(-PAY_STORE_CAP)` **нет**.
- Аварийный потолок файла (например 200k строк после per-customer): truncate самых старых poll-окон, не «хвост массива как попало».

`save()` в `crm-pay.ts` перевести на `capPaysByCustomer`.  
`mergePayInbound` не менять: дубль id нет, пустая сумма не затирает.

`complete[]` филиала не ставить от 3-дневного poll. Poll как сейчас: окно дат, `via: "auto"`.

**Не убивать** `rastudio-pay-poll`.

`conductorStep` **не** вызывает `pollPaysFromAlfa`. Слот 2 дирижёра всегда skip.

`payDays` читать из alfa-link.  
`payCronMin` в UI: «интервал процесса 15 мин, смена с деплоем ecosystem». Не «действует со следующего тика».

## 4. Занятия коллег — короткий inbound

Новые: `crm-colleague-lessons-core.ts` + `crm-colleague-lessons.ts`.

`POST lesson/index`  
`date_from` / `date_to` = сегодня МСК ± `colleagueDays` (завод 3: вчера, сегодня, вперёд тот же N, чтобы «завтра 17:00» было видно).  
Статусы: план + проведено (1 и 3). Отмену (2) тоже, чтобы слот освободить.  
**Без** `customer_id`, **без** `group_id`.  
Фильтр типов: 3 пробное, 1 индив, 4 makeup, 10 доп, 11 сверхурочное, 5 и разовые `isOneOffLesson`.  
**Тип 2 групповой ритм — выкинуть.** Не `regular-lesson`.  
Лето/camp — только если `canOfferSummer(policy, now, branchId)` (хелпер общий с этапом 7: `live.summer && апрель–август && (филиал 4 или тип camp/summer)`). Иначе drop строк кэмп.

Пагинация: pageSize 50, не больше 4 страниц на статус на филиал за слот. Остальное — курсор `storage/crm-colleague-cursor.json`. Не весь Alfa за раз.

**Запись на диск**

1. Индекс занятости `storage/crm-desk-occupancy.json`:  
   ключ `branchId|date|timeFrom|teacherId` и отдельно `branchId|date|timeFrom|roomId`.  
   значение: `{ lessonId, typeId, customerIds[], teacherId, roomId, status }`.  
   Склейка по `lessonId`. Отмена → убрать из индекса.  
   TTL: выкидывать ключи старше 2×N дней.
2. Календарь **упомянутых** `customerId`: `mergeLocalCalendar(union)` только этих уроков, **не** full journal, **не** `lessonsFull`. Штамп `source: "colleague"` / `colleagueAt`.

Не `fanOut` на всю группу. Не ставить явки квартала.

`colleagueDays === 0` → слот conductor skip. Индекс не чистить пачкой (TTL).
