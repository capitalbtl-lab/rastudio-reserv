## Когда какое окно

| Состояние диска | Проба | Посадка |
|---|---|---|
| Нет `lessonsAlfaAt`, нет seen, «С нуля» | `date_from=2015-01-01`, `date_to=сегодня+90` | качка / missing |
| Есть keep и seen, слева short/extra | окно по `lessonsWindowDays` (старт **30**) | missing по id дырок; качка только slow |
| Справа, синяя | ±месяц как сейчас | prune в окне |
| После 30 не сошлись множества | 90 | то же |
| После 90 не сошлись | 180 | то же |
| После 180 не сошлись | **не** снова 2015 автоматом. Галка или «С нуля» | — |

Окно: `from = сегодня − N дней`, `to = сегодня + N дней` (завтра и вчера входят). N=30/90/180. Не обрезать верх ниже сегодня: пробное на завтра должно попасть уже на 30.

Эскалация только если после этого захода `lessonsHoleN` или `lessonsExtraN` > 0 (extra не с group-card). Сошлось → `lessonsWindowDays` удалить. «С нуля» → ключ удалить, дальше строка «нет счёта».

Slow (10 мин): те же окна. Месячные чанки **внутри окна**, не до 2015, пока окно не полное. Полный floor 2015 — только ветка «нет счёта».

## Missing (знакомый id)

Цикл филиал × status 3→1→2. Тело `{ page:0, pageSize:5, id, status }`.

- Нет `items[].id` → следующий status/филиал.  
- Есть id, нет дня / `packLight` null → **не break**, следующий status/филиал. Лог `no-date`.  
- Села строка → stop по этому id. Upsert по id.  
- Все ответы `ok` и пусто / foreign → снять id со seen, лог.  
- `ok: false` / 429 → **не** снимать.

Состав = `customer_ids` ∪ `details[].customer_id`:

| Состав | Диск |
|---|---|
| cid в составе | сажать |
| пусто + group_ids | сажать, дописать cid |
| пусто без групп | сажать, дописать cid |
| не пусто, cid нет | не сажать, снять seen, `foreign` |

Качка тем же правилом состава. Не `{ ...item, customer_ids: [..., cid] }` вслепую.

`setTimeout` 700 после unlock — **удалить**. Курсор на диске.

«Добрать» по-прежнему не читает всю историю: 50 id + окно. Яма 186 — slow внутри окна, не одна кнопка с 2015.
