### Группа

| Поле | Кто |
|---|---|
| `journalFill.pulled[q]` / `done` | загрузка квартала |

| `journalFill.rechecked[q]` | «Перепроверить» **этого** зерна |
| `detailsAt` на уроке | кнопка деталей, не явки |
| `windowAt` | **завести пустым**. Пишет только этап 4 |

Патч `patchPeopleSide` / ответ `journalPull`:

- шаг `students` **не** трогает `pays`, `paysRechecked`, `alfa` (если probe не в этом же запросе);
- шаг `balance` **не** трогает `rechecked` календаря;
- probe ставит **только** `alfa` + жёлтый `short` если диск < Alfa.

Текст UI:

- «счёт с Alfa ещё не сверяли» → **«число занятий с Alfa ещё не сверяли»**
- «Сверить счёт» → **«Сверить число»**

`HINT.probe`: не качает журнал, не закрывает кассу, не ставит ✓ кварталу.

## 3. Что значит «загрузка завершена»

Вынести в `src/data/crm-journal-complete-core.ts` (без UI, без fs).

**Группа, правый столбец (явки):**

```
parts.length > 0
AND каждый part срока жизни: done && !weak
AND needDetails НЕ участвует в переезде
AND 0 уроков при done без явного «в Alfa 0» — не complete (0/0)
```

Детали — чекбоксы на карточке.

**Ученик, шаг 1, вправо:** `journal && !short`  
`alfa == null` **не** держит слева. Серая строка «число ещё не сверяли».  
`short` (диск < Alfa) — **жёлтый справа**, не уезжает влево. Слева только нет журнала.

**Ученик, шаг 3, вправо:** `pays && !payShort`  
Журнал шага 1 **не** обязателен. Подпись: «касса на месте; календарь — шаг 1».  
**Не** `journal && pays`.

Читать с диска политики: `history.zeroNotDone`, `cappedYellow`, `shortNotComplete`. Не читать `history.enabled`.
